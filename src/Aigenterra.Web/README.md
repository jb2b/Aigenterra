# Aigenterra Flight Recorder

Angular 22 developer UI for inspecting recorded executions through Aigenterra.Api.

Start the full stack from the repository root:

```powershell
dotnet run --project src/Aigenterra.AppHost --launch-profile http
```

Open the web resource in the Aspire dashboard. Angular CLI is project-local.
See [development and acceptance instructions](../../docs/development/flight-recorder.md)
for prerequisites, separate frontend startup, proxy routing, tests and known limits.
